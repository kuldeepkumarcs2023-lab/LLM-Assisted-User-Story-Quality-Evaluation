LLM API SETUP

1. Set the API key only in your local terminal/session; never put it in source code or commit it to GitHub.
PowerShell:
$env:OPENAI_API_KEY="YOUR_NEW_API_KEY"

2. Optional model override:
$env:OPENAI_MODEL="gpt-6-luna"

3. Start:
python app.py

4. If the app reports that API billing/credits are unavailable, add API credits to the API account and retry.

5. If no OPENAI_API_KEY is configured, the app intentionally uses the Local Quality Engine.
